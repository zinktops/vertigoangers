# Images du projet

Déposez dans ce dossier les images utilisées par le site (photos, illustrations ou logo).

Pour afficher une image locale dans `index.html`, indiquez son chemin relatif, par exemple :

```js
photo: "images/jardin-des-plantes.jpg"
```

Les images déjà référencées par la carte proviennent actuellement de Wikimedia Commons.

Le logo `logo_VERTIGO.png` conserve la transparence autour de son contour circulaire.
Le favicon `favicon-512.png` est généré à partir de ce logo.
